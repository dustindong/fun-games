Order Up!

Five things, one topic. Put them in order before the clock runs out. Closest order wins.

1. Read the topic

Every round has a topic, like country population, movie box office or video game sales. Everyone gets the same five things.

2. Sort the list

Drag the rows or use the arrows. Each round tells you what goes on top, like biggest first or oldest first.

3. Lock in by 30 s

Ten rounds per game. Lock in when you're happy. Pressing Lock in counts even if you didn't move anything.
